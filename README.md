# fib-pages

Service pages for **Fill in the Blank Generator** (Chrome extension): highlight a text on any page, snap a photo, or let AI write one —
and get a worksheet with gaps and an answer key.

- [`welcome/`](welcome/) — opens once, right after the extension is installed; its single job is to get the extension pinned and opened.
- [`uninstall/`](uninstall/) — opens after the extension is removed; one question: why.
- [`privacy/`](privacy/) — privacy policy.

Served with GitHub Pages.
